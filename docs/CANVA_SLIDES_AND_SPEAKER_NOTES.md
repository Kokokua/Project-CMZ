### Slide 5: กฎเวลาและการสลับสถานะ (Temporal Logic & State Machine)
- **Canva Layout**: ผังไดอะแกรมกล่อง State Machine (Active ⇄ Inactive) พร้อมกล่องอธิบายกฎ 1 นาที
- **รูปภาพประกอบที่ใช้**: กราฟิก State Machine (ตามที่ระบุในเนื้อหา) และไฮไลท์คำสั่งจาก [`slide/5.png`](file:///D:/CMU/4th/1%20st/image%20processing/project%20cmz/slide/5.png)

#### 📝 ข้อความบนสไลด์ (Slide Content):
> **หัวข้อ (Heading)**:  
> **ตรรกะทางเวลาและ State Machine (The 1-Minute Rule)**
>
> **ที่มาของกฎจากสวนสัตว์**: *"Duration : Behavior changes if they spend more 1 minute."*
>
> **สถาปัตยกรรม State Machine แบบ 2 ระดับ**:
> 1. **Macro State (Active ⇄ Inactive)**: ควบคุมด้วยกฎ 1 นาที (Hysteresis / Debounce)
>    - **Active ➔ Inactive**: ชะมดต้องอยู่นิ่งต่อเนื่องครบ **1 นาที** ถึงจะเปลี่ยนสถานะ (หยุดยืน 10 วินาที ไม่หลุดสถานะ)
>    - **Inactive ➔ Active**: ชะมดต้องเริ่มเคลื่อนไหวต่อเนื่องครบ **1 นาที** จึงจะเปลี่ยนสถานะ (แค่นอนพลิกตัว ไม่ทำให้ตื่นเท็จ)
> 2. **Micro Events (Sub-actions ภายในช่วง Active)**:
>    - การเดินสั้นๆ (8–28 วินาที) บันทึกเป็น `Locomotion`
>    - การก้มกินอาหาร บันทึกเป็น `Eating` และเพิ่มรอบความถี่ (Frequency count)

#### 🎙️ บทพูดนำเสนอ (Speaker Notes - 50 วินาที):
> *"หัวใจสำคัญของระบบเราคือการแก้ปัญหาทางชีววิทยาด้วยตรรกะทางคอมพิวเตอร์ครับ ในสไลด์ของสวนสัตว์ระบุชัดเจนว่า 'จะนับว่าเปลี่ยนพฤติกรรมก็ต่อเมื่อทำสิ่งนั้นเกิน 1 นาที' เราจึงนำหลักการ Finite State Machine ที่มี Debounce มาใช้ โดยแบ่งเป็น Macro State คือ Active และ Inactive ซึ่งต้องคงสถานะต่อเนื่องครบ 1 นาทีถึงจะสลับสถานะ เพื่อป้องกันไม่ให้ระบบกระตุกเปลี่ยนสถานะไปมา และเมื่ออยู่ในสถานะ Active กิจกรรมย่อยอย่างการเดินข้ามห้อง 10–20 วินาที หรือการแวะกินอาหาร ก็จะถูกบันทึกเป็น Event ย่อยได้อย่างถูกต้องครบถ้วนครับ"*

### Slide 6: สถาปัตยกรรมระบบรวม (End-to-End System Pipeline)
- **Canva Layout**: ผังกระบวนการแบบ Flowchart 5 ขั้นตอน (ลูกศรชี้จากซ้ายไปขวา)

#### 📝 ข้อความบนสไลด์ (Slide Content):
> **หัวข้อ (Heading)**:  
> **ภาพรวมสถาปัตยกรรมระบบ (End-to-End System Pipeline)**
>
> **ขั้นตอนการประมวลผล 5 สเต็ป**:
> 1. **Video Ingestion & Downsampling**:
>    - รับสัญญาณวิดีโอ 1080p จาก 4 กล้อง ➔ ลด Sampling Rate เหลือ **2 FPS** (ลดโหลด 7.5 เท่า)
> 2. **Object Detection (YOLOv8)**:
>    - ตรวจหาพิกัด Bounding Box ของตัวชะมดในแต่ละเฟรม
> 3. **Spatial & Motion Extraction**:
>    - คำนวณระยะการเคลื่อนที่ (Centroid Displacement $\Delta X, \Delta Y$) + ตรวจสอบโซนอาหาร (Food Zone ROI)
> 4. **Temporal Rule Engine (FSM)**:
>    - กรองสถานะ Macro State (Active/Inactive) และตัดสิน Micro Events ตามเกณฑ์เวลา
> 5. **Multi-Camera Fusion & Event Output**:

### Slide 9: แผนการประเมินผล (Evaluation Plan & Split Strategy)
- **Canva Layout**: 2 การ์ด (ซ้าย: เกณฑ์ชี้วัด Metrics / ขวา: การแบ่งข้อมูล Split Strategy)

>
> **1. ตัวชี้วัดประสิทธิภาพ (Evaluation Metrics)**:

> - **ห้ามสุ่มตามเฟรม (No Random Frame Split)** เพื่อป้องกันปัญหา **Data Leakage** ที่เฟรมติดกันหน้าตาเหมือนกันจะหลุดเข้าไปในชุดทดสอบ
> - แบ่งตามวันที่: วันที่ 18 พ.ค. (Train) ➔ วันที่ 19 พ.ค. (Val) ➔ วันที่ 20 พ.ค. (Test)
